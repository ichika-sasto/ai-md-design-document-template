# ai-md-design-document-template

設計書のテンプレートを管理するリポジトリです。

## 概要

システム開発で使う各種設計書のテンプレートを、Markdown 形式でまとめています。
新しく設計書を作るときは、ここからテンプレートをコピーして使います。

## 前提・方針

- **ドメイン駆動設計（DDD）を前提としています**
  - 設計書はドメインごとに作成します
  - アグリゲート（集約）の構造を設計書の中で表現できる形式にしています
- **開発者向けの設計書です**
  - 製造（実装）に入る前に、設計内容を確認するためのものです
  - 顧客との折衝や、顧客への説明に使うことは想定していません

## 使い方

1. このリポジトリから、作りたい設計書のテンプレートを選ぶ
2. テンプレートを自分のプロジェクトにコピーする
3. 各項目を埋めて設計書を仕上げる

## テンプレートの追加・更新

- テンプレートは Markdown（`.md`）形式で作成してください
- 新しいテンプレートを追加したときや既存のものを変えたときは、この README にも反映してください
